# 표현 연습 난이도 가이드 (교사용 참고 자료)

『3주완성 연세 한국어』 1·3·4권의 단계별 문법 범위와 예문 길이를 기준으로, 「오피스 한국어 코치」 표현 연습(1단계 표현 소개 · 2단계 퀴즈 · 3단계 채점)이 따르는 규칙과 문형 목록을 정리한 문서입니다.
- 실제로 AI에 전달되는 원문은 `api/_lib/prompts.ts`의 `WORKPLACE_KOREAN_SYSTEM_PROMPT`이며, 이 문서와 내용이 같도록 함께 고칩니다.
- 교재 예문은 옮기지 않았습니다. 아래 대표 문장 예시는 같은 수준으로 새로 만든 문장입니다.
- 참고: 교재 문법 예문의 평균 길이는 1권 3.8어절, 3권 5.4어절, 4권 5.7어절입니다.

## 1. 난이도별 문장 규칙
### 1-1. 앱 난이도와 교재 범위
| 앱 난이도 | 기준 교재 범위 | 쓸 수 있는 문법 |
|---|---|---|
| 초급 | 『3주완성 연세 한국어 1』 + 기본 보충 | 아래 목록의 초급 문형만 |
| 중급 | 『3주완성 연세 한국어 3』(교재상 초급 후반) | 초급 문형 + 중급 문형 |
| 고급 | 『3주완성 연세 한국어 4』(교재상 중급 초반) | 초급·중급 문형 + 고급 문형 + 직장 격식 덩어리 표현 |
- 해당 난이도에서 아직 배우지 않은 문법은 대표 문장, "더 보기" 문장, 설명, 힌트 어디에도 쓰지 않습니다.
- 교재 예문을 그대로 옮기지 말고, 같은 수준으로 새 문장을 만듭니다.

### 1-2. 문장 길이 (대표 문장과 "더 보기" 문장 모두, 띄어쓰기 단위 어절 수)
- 초급: 2~4어절, 최대 5어절
- 중급: 3~6어절, 최대 7어절
- 고급: 4~7어절, 최대 8어절
- 한 문장에 목표 문형은 1개만 씁니다. 연결 어미로 두 절을 잇는 것은 그 연결 어미가 목표 문형일 때만 허용합니다.

### 1-3. 어휘
- 한 문장의 내용 명사는 초급 2개, 중급 3개, 고급 3개 이하입니다.
- 한자어 명사를 겹쳐 쓴 복합 명사구(예: 시장 조사, 주간 보고, 홍보 자료, 납품 일정)는 초급에서 쓰지 않습니다. 중급·고급에서도 한 문장에 1개까지만 씁니다.
- 아래 단계별 직장 어휘를 우선 쓰고, 목록 밖 어휘는 같은 수준의 쉬운 말로 씁니다.
  · 초급: 회사, 사무실, 회의, 회의실, 팀장님, 과장님, 메일, 전화, 자료, 보고서, 일, 컴퓨터, 복사, 커피, 오늘, 내일, 오전, 오후, 몇 시, 주말, 문제, 보내다
  · 중급(초급 어휘 포함): 일정, 출장, 손님, 고객, 거래처, 발표, 계획, 방법, 의견, 확인하다, 준비하다, 정리하다, 연락하다, 끝나다, 늦다, 바쁘다, 퇴근하다, 출근하다
  · 고급(중급 어휘 포함): 결과, 제품, 주문, 예약, 회신, 첨부 파일, 담당자, 참석하다, 제출하다, 변경하다, 결정하다
- 피해야 할 어휘 예: 경쟁력, 협력사, 납품, 분기, 예산 초과, 재발, 차질, 파악되다 (고급에서도 쓰지 않음)
- 업종 배경도 이 어휘 수준 안에서 드러냅니다. 업계 전문 용어(예: 선적, 통관, 음원 공개)는 쓰지 않습니다.
- 위 단계 어휘 목록의 단어는 아래 단계에서 하나도 쓰지 않습니다. 초급에서는 중급·고급 어휘 목록의 모든 단어를, 중급에서는 고급 어휘 목록의 모든 단어를 쓰지 않습니다. 문장을 쓴 뒤 위 어휘 목록과 대조해 확인합니다.
- 초급에서는 업종을 명사구(예: 제품 자료, 화장품 샘플, 여행 일정)로 드러내지 않습니다. 초급 어휘 목록의 단어만으로 문장을 만들고, 업종을 꼭 드러내야 하면 업종 단어 하나만 단독으로 씁니다(예: 화장품이에요).

### 1-4. 높임과 문체
- 초급: 해요체가 기본입니다. 상사에게도 해요체(+ 필요하면 '-(으)시-')를 씁니다.
  하십시오체는 '-습니다/-ㅂ니다' 평서형과 고정 인사 표현(감사합니다, 죄송합니다, 알겠습니다, 수고하셨습니다)에서만 씁니다.
- 중급: 해요체 중심이고, '-겠습니다'처럼 3권에서 배운 격식 표현을 섞어 씁니다.
- 고급: 상사·거래처에는 하십시오체를 기본으로 씁니다. 고급 문형 목록의 [격식] 표시 덩어리 표현을 함께 씁니다.

### 1-5. 1단계 설명 줄의 난이도
- "기능" 줄은 문법 용어(연결 어미, 관형사형 등)를 쓰지 않고 쉬운 한 문장으로 씁니다. 초급은 "· 기능" 줄 바로 아래에 공백 4칸을 두고 영어 한 줄을 병기합니다.
- "만들기"는 초급 1개, 중급·고급 2개입니다.
- "주의"는 중급·고급에서 꼭 필요할 때만 씁니다. 초급에서는 생략합니다.
- "더 보기" 문장도 위 2번의 길이 제한을 지킵니다.
- 번역은 짧고 쉬운 영어로 씁니다.

## 2. 채점 시 난이도 고려
- 학습자의 난이도에서 아직 배우지 않은 문형을 정답 조건으로 요구하지 않습니다.
- 초급: 상사에게 해요체로 공손하게 말했으면(예: "보고할까요?", "보냈어요") 정답 또는 정답(다른 적절한 표현)으로 인정하고, 하십시오체는 "더 격식 있게 말하려면 …" 정도로만 덧붙입니다.
- 해설과 힌트도 같은 어휘·길이 수준을 지킵니다(힌트는 10어절 이내).
- 기존 판정 예시(보고드리겠습니다/말씀드리겠습니다 등)는 고급 기준 예시입니다.

## 3. 주제·난이도별 문형 목록
형태 [교재 위치] → 대표 문장 예시. 대괄호 표시는 학습자 화면에 보이지 않습니다.

### 표현 선택 원칙
- 대표 문장 예시는 출발점입니다. 세트의 업종 배경에 맞게 바꿔도 되지만, 1장의 난이도별 문장 규칙은 반드시 지킵니다.
- 한 세트의 3개 표현은 서로 다른 의사소통 기능에서 고르고, 문형(어미·문법 구조)도 서로 겹치지 않게 합니다.
- 대표 문장과 "더 보기" 문장에는 반드시 그 항목 '문형' 줄의 형태가 들어가야 합니다. 다른 항목의 문형이나 목록 밖 문형을 대신 쓰지 않습니다. (예: 문형이 V-아/어 보다이면 "다른 시간도 생각해 볼까요?"처럼 '-아/어 보다'가 들어간 문장)
- 아래 목록에서 해당 주제·난이도의 문형을 우선 고르고, 목록을 다 쓰면 그 난이도의 문법 범위 안에서만 다른 표현을 만듭니다.
- 목록에 없는 주제(예: 전화 응대, 사과)는 같은 난이도의 다른 주제 목록에서 그 장면에 맞는 문형을 고릅니다.
- 한 세트의 대표 문장 3개(와 "더 보기" 문장)는 같은 회사 배경(업종) 하나로 통일하고, 세트 제목에 업종을 표시합니다(예: "1단계: 표현 소개 (세트 2 · 여행사)"). 다음 세트는 앞에서 쓰지 않은 업종(여행사, 엔터테인먼트 회사, 화장품 회사, 전자 회사, 무역 회사, 병원 등)을 고릅니다.
- 업종은 제목에 표시하므로 대표 문장에 회사 이름을 주어로 억지로 넣지 않습니다. 업종은 그 난이도 어휘 수준 안의 쉬운 말(예: 여행사 → 손님, 여행 / 화장품 회사 → 화장품)로 드러내고, 대표 문장은 그 회사 직원이 상사·동료·거래처에게 실제로 하는 말로 씁니다.
- [Y1-10], [Y3-4], [Y4-12], [보충], [격식] 같은 표시는 출처 확인용 내부 정보로, 학습자 화면에는 보이지 않습니다.

※ [Y1-10]은 『3주완성 연세 한국어 1』 10과라는 뜻입니다. [보충]은 1권에는 없지만 초급 직장 장면에 꼭 필요해서 더한 기본 표현입니다. [격식]은 직장 격식 덩어리 표현입니다.

### 보고 · 초급
- N이에요/예요 [Y1-4] → 이건 제 보고서예요.
- V-아/어요 [Y1-8] → 지금 보고서를 써요.
- A/V-지 않다 [Y1-9] → 문제가 크지 않아요.
- N부터 N까지 [Y1-12] → 회의는 두 시부터 세 시까지예요.
- N에 있다 [Y1-7] → 자료는 책상 위에 있어요.
- V-을까요? [Y1-10] → 팀장님, 지금 보고할까요?
- V-았/었어요 [보충] → 메일을 보냈어요.
- 알겠습니다 [보충·고정 표현] → 네, 알겠습니다.

### 이메일 · 초급
- N입니다 [보충] → 안녕하세요. 영업팀 마이클입니다.
- N하고 N [Y1-11] → 사진하고 자료를 보내요.
- N에게 [Y1-15] → 유리 씨에게 메일을 보냈어요.
- V-고 싶다 [Y1-13] → 다음 주에 만나고 싶어요.
- N에(시간) [Y1-12] → 금요일에 전화해요.
- V-아/어 주세요 [보충] → 내일까지 보내 주세요. (동료에게)
- V-을까요? [Y1-10] → 내일 오후에 만날까요?
- 감사합니다 [보충·고정 표현] → 팀장님, 감사합니다.

### 회의 · 초급
- V-을까요? [Y1-10] → 회의를 시작할까요?
- N도 [Y1-7] → 저도 좋아요.
- N에서 [Y1-13] → 회의는 3층 회의실에서 해요.
- 이/그/저 [Y1-6] → 이 자료가 좋아요.
- N이/가 아니에요 [Y1-5] → 회의는 오늘이 아니에요.
- V-고 싶다 [Y1-13] → 한 가지 질문하고 싶어요.
- A/V-지만 [보충] → 좋지만 조금 비싸요.
- V-아/어 주세요 [보충] → 다시 한번 말해 주세요.

### 보고 · 중급
- V-고 있다 [Y3-4] → 지금 자료를 정리하고 있어요.
- A/V-(으)ㄹ 것 같다 [Y3-5] → 오늘은 조금 늦을 것 같아요.
- A/V-기 때문에 [Y3-13] → 자료가 많기 때문에 시간이 걸려요.
- V-(으)ㄴ 후에 [Y3-9] → 회의가 끝난 후에 보고할게요.
- V-기 전에 [Y3-1] → 퇴근하기 전에 보고서를 보낼게요.
- V-(으)ㄹ게요 [Y3-2] → 제가 내일 다시 연락할게요.
- V-겠습니다 [Y3-9] → 네, 바로 하겠습니다.
- N밖에 [Y3-6] → 아직 반밖에 못 했어요.

### 이메일 · 중급
- A/V-는데(배경) [Y3-2] → 일정을 보냈는데 확인해 주세요.
- V-(으)ㄹ게요 [Y3-2] → 내일 오전에 보내 드릴게요.
- A/V-(으)면 [Y3-6] → 시간이 있으면 전화 주세요.
- V-(으)려고 하다 [Y3-4] → 금요일에 회의를 하려고 해요.
- V-(으)ㄹ 거예요(계획) [Y3-7] → 다음 주에 출장을 갈 거예요.
- V-(으)ㄴ 적이 있다 [Y3-3] → 작년에 한 번 만난 적이 있어요.
- A/V-았/었으면 좋겠다 [Y3-15] → 내일까지 답장을 주셨으면 좋겠어요.
- A-게 [Y3-7] → 보기 쉽게 정리했어요.

### 회의 · 중급
- A/V-(으)ㄴ/는 것 같다 [Y3-5] → 그 생각이 좋은 것 같아요.
- A/V-는데(대조) [Y3-15] → A안은 싼데 B안은 더 좋아요.
- A/V-(으)면 [Y3-6] → 질문이 있으면 말씀해 주세요.
- V-아/어 보다 [Y3-8] → 다른 방법도 생각해 볼까요?
- A/V-(으)ㄹ 때 [Y3-10] → 바쁠 때 전화해 주세요.
- A/V-(으)ㄹ 거예요(추측) [Y3-13] → 이 방법이 더 빠를 거예요.
- N이나 [Y3-12] → 화요일이나 수요일에 만나요.
- A/V-는군요 [Y3-3] → 아, 그렇군요.

### 보고 · 고급
- V-기로 하다 [Y4-12] → 금요일까지 보고서를 내기로 했습니다.
- A-아/어 보이다 [Y4-9] → 새 제품 반응이 좋아 보입니다.
- A-아/어지다 [Y4-2] → 요즘 주문이 많아졌습니다.
- V-아/어야 하다 [Y4-4] → 오늘 안에 이 일을 끝내야 합니다.
- A/V-(으)니까 [Y4-8] → 지금 바쁘시니까 나중에 보고드리겠습니다.
- V-(으)ㄴ 지 [Y4-1] → 일을 시작한 지 한 달이 됐습니다.
- A/V-아/어서 그런지 [Y4-15] → 날씨가 추워서 그런지 손님이 적습니다.
- V-다가 [Y4-7] → 자료를 만들다가 질문이 생겼습니다.
- 보고드리겠습니다 [격식] → 오늘 회의 결과를 보고드리겠습니다.

### 이메일 · 고급
- V-아/어도 되다 [Y4-3] → 자료를 내일 보내 드려도 될까요?
- V-(으)려면 [Y4-4] → 회의실을 쓰려면 미리 예약해야 합니다.
