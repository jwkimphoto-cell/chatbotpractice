# 실제 응답 표본 검증 결과 (단계 3)

- 실행: `node --import ./scripts/ts-register.mjs scripts/eval.mjs` (원문은 eval-out/에 저장, gitignore)
- **API 호출: 79회 / 한도 80회** (1차 전체 64회 → 1회차 수정 후 4회(스크립트 필터 오류로 D 그룹이 빠짐) → 2회차 10회 → 단순화 확인 1회). 429 없음.
- 판정은 두 겹: ① 스크립트 자동 검사(형식·어절 상한·금지 어휘·내부 표시·{{n}}·세트 간 중복) ② Claude Code가 품질 채점표 6항목(1 문법성, 2 화용, 3 난이도, 4 논리 일관성, 5 형식, 6 교육적 타당성)을 모두 확인. 한 항목이라도 미달이면 불합격.
- 표의 판정은 각 표본의 **마지막 생성본** 기준. 도움 표본은 화면의 자동 재요청 없이 **첫 응답만** 평가했으므로 실제 화면보다 엄격한 기준임.

- 회귀 세트 B·C는 8개 모두 기대 판정과 일치.
- 불합격 17개 중 12개는 한도 때문에 재생성하지 못한 표본. 그중 피드백 3개(직접 쓴 발화 오판)는 같은 원인을 고친 뒤 다른 3개 표본에서 해결을 확인함.
